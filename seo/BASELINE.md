# AI Tool Gems SEO Baseline

Baseline date: 2026-09-19
Site: https://aitoolgems.tech/
Market: Pakistan

## Verified locally and against the public site

- 32 sitemap URLs are present and reachable with HTTP 200.
- Public sitemap URLs map to files in the repository.
- Important public pages expose a title, meta description, canonical URL, and one primary H1.
- Homepage exposes Organization/OnlineStore, WebSite, WebPage, and ItemList JSON-LD.
- Product pages expose Product/Offer and BreadcrumbList JSON-LD.
- `robots.txt` references the XML sitemap and permits the public site.
- `/.env`, `/.env.example`, `/admin.html`, and `/marketing_agent/` are disallowed.
- Homepage and public sitemap integrity are checked by `marketing_agent seo-monitor`.
- Python test suite passes with 33 tests.
