# Security Policy

## Supported Versions

AIToolGems is continuously maintained and deployed on the `main` branch.

| Version | Supported |
| ------- | ------------------ |
| Latest (`main`) | :white_check_mark: |

## Reporting a Vulnerability

The AIToolGems engineering team takes the security of our platform and Pakistani digital transactions seriously. We appreciate responsible disclosure.

If you discover a security issue or potential vulnerability:

1. **Do NOT** open a public GitHub issue, pull request, or discussion.
2. Email your findings privately to **<mrehmanfarooq6@gmail.com>** or **<support@aitoolgems.tech>**.
3. Please include:
   - Description of the vulnerability
   - Step-by-step instructions or proof-of-concept to reproduce
   - Affected URLs or modules
   - Potential impact on users, schemas, or payment verifications

### Response Timeline

- **Initial acknowledgment:** Within 24 hours.
- **Triage & fix:** Within 48–72 hours depending on severity.
- **Public acknowledgment:** Credited upon request after the fix is safely deployed.

## Security Architecture & Practices

- **No Sensitive Financial Data Stored:** AIToolGems operates on verified direct escrow and official Pakistani instant payment rails (JazzCash, EasyPaisa, SadaPay, Raast, Bank Transfer). No credit card numbers or banking credentials are ever collected or stored in this repository.
- **Automated Code Quality & Secret Scanning:** Continuous SAST scanning, push protection, and automated dependency vulnerability alerts are active across all autonomous SEO and marketing agent workflows.
