About Bolt.new

Bolt.new harnesses StackBlitz's groundbreaking WebContainer technology to execute Node.js runtimes directly inside browser tabs. Paired with Anthropic's Claude Sonnet, Bolt.new can install npm dependencies, compile code, configure databases, fix compilation errors autonomously, and provide a live URL—all without local Node.js installation or terminal configuration.

Key Features

  • In-Browser Node.js Runtime: Runs a complete WebContainer execution environment inside your browser with full npm support.
  • Autonomous Multi-File Generation: Scaffolds complete full-stack web applications including package.json, routes, API endpoints, and styling.
  • Real-Time Error Auto-Correction: Captures console and terminal runtime exceptions and prompts the AI model to fix them automatically.
  • One-Click Netlify Deployment: Deploy your running browser web application to a live public URL on Netlify in under 10 seconds.
  • GitHub Repo Export: Push the generated codebase directly to a new or existing GitHub repository with commit history.

Primary Use Cases

  • Rapid Full-Stack MVP Prototyping: Build working software prototypes for clients or hackathons in under an hour without local setup.
  • Interactive Frontend Exploration: Experiment with modern UI libraries (Remix, Next.js, SvelteKit, Astro) instantly in the browser.
  • Bug Replication & Sharing: Share an interactive live environment URL with colleagues to demonstrate bugs or features.
  • Database & API Integration: Build apps that integrate third-party APIs (Stripe, Supabase, OpenAI, Weather) seamlessly.

Frequently asked questions

Is Bolt.new free to use in Pakistan?

Yes, Bolt.new has a free tier that gives you daily token quotas to build and run web applications in your browser without requiring a credit card.

Can Bolt.new run backends and databases?

Yes, because Bolt.new runs on WebContainers, it executes full Node.js backends like Express, Next.js server actions, and connects to cloud databases like Supabase or Firebase.

How do I export my project from Bolt.new?

You can push your project directly to GitHub with one click, deploy it to Netlify, or download the entire project directory as a ZIP file to open locally in VS Code or Cursor.

What AI model does Bolt.new use?

Bolt.new primarily uses Anthropic's Claude Sonnet due to its superior coding and multi-file architectural reasoning capabilities.

Can I pay for Bolt.new using SadaPay or NayaPay in Pakistan?

Yes, SadaPay and NayaPay debit cards work on StackBlitz's official Stripe checkout for Bolt.new Pro subscriptions.
