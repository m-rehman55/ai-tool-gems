About Morphic AI

Morphic was developed as an open-source answer to proprietary AI search engines like Perplexity. Built with Next.js and the Vercel AI SDK, Morphic performs real-time web queries using search APIs like Tavily and SearXNG, synthesizes the results with top frontier models (Claude Sonnet, GPT-4o, or local Ollama models), and provides answers complete with numbered source citations, related follow-up questions, and interactive data visualizations.

Key Features

  • 100% Open Source Architecture: Full codebase available on GitHub; self-host on your own infrastructure with complete privacy.
