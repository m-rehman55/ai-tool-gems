About Supabase

The complete open-source backend-as-a-service built directly on dedicated PostgreSQL.

Supabase provides all the backend services developers need to build scalable products: dedicated PostgreSQL databases with full pgvector AI support, authentication with social logins, auto-generated secure APIs, realtime subscriptions, and serverless storage buckets.

Primary Use Cases

PostgresAuthFull-Stack DevsVector AI

Key Capabilities

  • Managed Postgres with pgvector
  • Instant REST and GraphQL APIs
  • Row Level Security (RLS)
  • Realtime websockets

Limitations & Considerations

  • Free projects pause after 1 week of inactivity
  • Storage egress overage charges apply
